# Shaurya Attreya — portfolio

A small, framework-free personal website built with semantic HTML and CSS.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Files

- `index.html` — content, page structure, and project glimpses
- `styles.css` — responsive light/dark styling, modal lightboxes, and print layout
- `particle-sheet.js` — interactive 3D particle terrain canvas simulation
- `floating-dock.js` — Aceternity-style floating dock with macOS magnification physics
- `assets/sa-logo.webp` — optimized site mark
- `assets/favicon.svg` — site icon
- `assets/rsna_assets/` — RSNA project screenshots and Jupyter notebook results
- `assets/physiverse_assets/` — Physiverse interactive simulation captures
- `assets/aether_assets/` — Aether badge prototype photo and companion app screens

The page has no build step, external dependencies, analytics, cookies, or external font requests.
